# AGENTS.md

Instructions for AI coding agents working on this project.

## Project
Smart Campus Room Availability Checker for Room 304 (Innovation Lab). React + TypeScript + Tailwind,
built with Vite. Python reference in `python/`.

## Commands
- Install: `npm install`
- Dev server: `npm run dev`
- Build: `npm run build`
- Lint: `npm run lint`

## Coding guidelines
- Use functional React components and hooks.
- Use Tailwind utility classes for styling; keep the layout responsive.
- Use `lucide-react` for icons.
- Keep the availability rules in sync with `python/booking.py`.

## Data
- Bookings are fictional sample data. Do not add booking creation or deletion.
